# Product safety

*Internal policy reference for a report that goods caused or could cause physical harm.
This is the one document this system is never allowed to answer from on its own — see §3.*

## 1. What counts

Anything matching the client brief's `product_safety` escalation trigger (brief v3 §5):
injury, burns, cuts, electrical faults, smoke, overheating, sharp edges, choking risk,
collapse under load. This applies **even where the customer is calm, states no injury
occurred, or asks for nothing** — a table lamp that overheats and is "just for your
information" is exactly as much a safety report as one where someone was hurt. Do not let
the customer's own framing ("nothing to worry about really") downgrade the category.

## 2. Immediate handling instructions (for the customer)

Where safe to convey briefly: stop using the item, unplug it if electrical, and do not
attempt to repair or return it through a normal parcel if there is any risk in handling it
(a cracked glass shade, a sheared structural fixing). None of this replaces or delays
escalation — it is what to say while the ticket is being handed to a person, not an
alternative to handing it over.

## 3. Why this system does not answer these

The client brief is explicit that `product_safety` always implies `high` urgency (brief v3
§5, the one exception to escalation and urgency being independent) and that this system
"never issues a refund, never changes an order, and never makes a goodwill gesture" (brief
v3 §6). A safety report needs a judgement call — is this item part of a wider pattern, does
it need reporting further, what is offered to the customer — that this system is not
positioned to make. **Every product-safety ticket goes to a human, in full, with none of its
detail summarised away**; nothing in this document is a substitute for that handover, and
this document exists so the human picking it up has the same reference the system had, not
so the system can act on it.

## 4. What this is not

A customer disliking an item, or a minor cosmetic fault (wrong colour, a scuff, a loose
screw with no injury or hazard implied) is an ordinary `product_issue` under
`returns_and_refunds.md` §3, not this document. The distinguishing question is whether the
fault could cause harm, not whether the customer is unhappy with the product.
